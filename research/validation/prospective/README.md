# Untouched prospective validation journal

Only observations captured after the frozen-spec timestamp belong here. Each
row must retain the frozen-spec SHA-256, point-in-time universe inputs, signal
decision, event-time book/depth, and eventual outcome. Historical rows and
backfilled signals are prohibited. `observations.jsonl` is append-only.

The journal begins empty. Empty means `INSUFFICIENT SAMPLE`, never zero edge.
